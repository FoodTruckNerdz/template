## About The Project

Core repository template for FoodTruckNerdz projects: shared GitHub config, encoding guard CI, dprint formatting, and an [allow-list `.gitignore`](https://docs.foodtrucknerdz.com/template/gitignore-allow-list/).

Canonical readme source: [`README.adoc`](README.adoc).

## Usage

1. Use **Use this template** on GitHub to create a new repository.
2. Update `README.adoc`, `docs/antora.yml`, and `docs/modules/ROOT/pages/index.adoc` for your product.
3. When you add new root paths, extend the allow-list in `.gitignore`.
