== About the project

Core repository template for FoodTruckNerdz projects: shared GitHub config, encoding guard CI, dprint formatting, and an allow-list `.gitignore`.

== Usage

. Use **Use this template** on GitHub to create a new repository.
. Update `README.adoc`, `docs/antora.yml`, and `docs/modules/ROOT/pages/index.adoc` for your product.
. When you add new root paths, extend the allow-list in `.gitignore` (see https://docs.foodtrucknerdz.com/template/gitignore-allow-list/[Allow-list `.gitignore`] on the docs site).
